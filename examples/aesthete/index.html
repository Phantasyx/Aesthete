Example 03

Connectivity study

Aesthete

Two seats share one board. Each owns a source and a gauge. A pipe can be added only where your own line is still open, and only if the piece opens back into that leak. The line is finished when every opening meets another opening and the gauge is connected.

Your line to move

The leak beside the source faces west. Fit a piece so it opens west, then click the marked cell.

The gold mark is the side the next piece must open. Copper is the upper line. Teal is the lower line.

  1. Select a piece that opens toward the gold mark.
  2. Click the marked cell. The leak moves to every new open end.
  3. Open the valve only when the line is closed through to the gauge.

Pieces

Commit

Opening the valve on a leak loses the seat. In a two-seat match, the other line takes it.

What the connection is

Each seat is trying to join two fixed ends: a source that opens east, and a gauge inlet that opens west. Pieces in between are caps, elbows, straights, and tees. A finished line has no bare end. Running a pipe off the board leaves an opening that can never be capped, so that route cannot win.

Where the two seats meet

The original online match stores the shared turn in MySQL. Each browser talks to a PHP application, and the waiting seat reloads every two seconds. The browsers never connect to each other. This page is the version that can live on a static host: one person plays a single line, or two people pass one device. The board never leaves the browser.

On the marketing site

Serve this folder at /examples/aesthete/. It is four files, with relative links, and it does not need a build or a database. The PHP match server remains in the repository for anyone who wants the original shared-turn setup.
